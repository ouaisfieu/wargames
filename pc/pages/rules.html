Le système en détail

◈ Les Fragments

Les Fragments sont l'unité de base de l'économie du Protocole. Ils représentent votre engagement et votre participation.

Sources de Fragments :

  • Navigation sur le site (+1 ◈ par nouvelle page)
  • Connexion quotidienne (+10 ◈)
  • Temps passé (+5 ◈ toutes les 5 minutes)
  • Missions accomplies (+10 à +500 ◈)
  • Secrets découverts (+25 à +200 ◈)
  • Bonus de niveau (+50 ◈ par niveau)

Stockage : Vos Fragments sont stockés localement dans votre navigateur. Vous pouvez les exporter/importer via la console (F12).

↑ Les Niveaux

Votre niveau détermine votre accès au contenu et vos privilèges dans le Protocole.

Niveau Seuil Privilèges
Observateur 0 ◈ Accès basique
Sentinelle 100 ◈ Dossiers restreints
Analyste 500 ◈ Missions avancées
Architecte 2000 ◈ Proposer des missions
Oracle 10000 ◈ Accès total + Gouvernance

⬡ Les Missions

Les missions sont des objectifs à accomplir pour gagner des Fragments. Il existe plusieurs types :

  • Onboarding — Missions de démarrage
  • Exploration — Visiter des pages spécifiques
  • Découverte — Trouver des secrets
  • Progression — Atteindre des paliers
  • Communautaire — Contributions collectives
  • Easter Eggs — Missions cachées

Les missions se complètent automatiquement quand les conditions sont remplies.

🔓 Les Secrets

Des Fragments sont cachés un peu partout sur le site. Voici quelques indices :

  • Certains éléments réagissent au clic
  • D'autres au double-clic
  • Certains se révèlent après un survol prolongé
  • La console développeur (F12) cache des surprises
  • Certaines séquences de touches sont... classiques
  • Les chiffres ont parfois un sens caché

Tapez USBA.hint() dans la console pour un indice.

⌨ La Console

La console développeur (F12) donne accès à des commandes spéciales :

USBA.hint() Obtenir un indice pour un secret
USBA.status() Voir votre statut complet
USBA.export() Exporter vos données
USBA.import(data) Importer des données

Fair Play

Le Protocole USBA est un jeu coopératif. Voici les règles de bonne conduite :

✓ Encouragé

  • Explorer, expérimenter, chercher
  • Partager des indices (pas les solutions directes)
  • Contribuer au développement
  • Signaler des bugs
  • Proposer des améliorations

✗ Découragé

  • Modifier le code pour tricher
  • Publier des solutions complètes
  • Automatiser la collecte de Fragments
  • Usurper l'identité d'autres Agents
