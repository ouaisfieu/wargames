// MANIFESTE

Le Protocole USBA

Unité de Suivi des Biens Activés — Une expérience de démocratie participative gamifiée.

// ORIGINE

Comment tout a commencé

Il y avait un répertoire. /usba/. Officiellement vide. Officiellement inexistant. Mais certains avaient remarqué des traces — des logs bizarres, des références dans du code source, des mentions dans des documents jamais publiés.

Ce répertoire contenait l'ébauche d'un système. Un système conçu pour mesurer ce qui n'a jamais été mesuré : la valeur de l'engagement citoyen.

L'idée était simple, presque naïve : et si chaque acte de participation — lire un article, signaler une irrégularité, documenter un événement local, voter, débattre, construire — générait une trace tangible ? Une preuve ? Une monnaie ?

Le Protocole USBA est né de cette idée. C'est un ARG — un jeu en réalité alternée — mais c'est aussi plus que ça. C'est une expérience sociale. Un prototype de ce que pourrait être une économie de la participation.

// LE MÉTA-JEU

Un ARG dans un ARG

Vous êtes tombé sur ce site. Peut-être par accident. Peut-être guidé par des indices disséminés ailleurs. C'est le premier niveau du jeu.

Le deuxième niveau, c'est de comprendre que le jeu lui-même est un outil. Les Fragments que vous collectez ne sont pas que des points. Ils documentent votre parcours d'apprentissage citoyen. Ils prouvent votre engagement.

Le troisième niveau — celui que nous construisons ensemble — c'est de transformer ce prototype en quelque chose de réel. Une vraie monnaie locale. Une vraie reconnaissance de l'éducation populaire. Une vraie infrastructure démocratique.

"Le jeu est la forme la plus élevée de la recherche."
— Albert Einstein

// PRINCIPES

Les règles du Protocole

1. Transparence totale

Tout le code est ouvert. Toutes les règles sont publiques. Il n'y a pas de mécaniques cachées (sauf les easter eggs, évidemment).

2. Méritocratie participative

Les Fragments ne s'achètent pas. Ils se gagnent par l'action. Votre influence dans le Protocole reflète votre engagement réel.

3. Gouvernance distribuée

Les décisions majeures sont prises collectivement. Les Agents de haut niveau proposent, tous les Agents votent.

4. Évolution permanente

Le Protocole est vivant. Il s'adapte. Les règles peuvent changer si la communauté le décide. Rien n'est gravé dans le marbre.

// CRÉDITS

Qui sommes-nous ?

Le Protocole USBA est un projet d'éducation populaire et de veille citoyenne. Il est développé de manière ouverte et collaborative.

Ce projet s'inscrit dans une démarche de reconnaissance via le Décret Éducation Permanente de la Fédération Wallonie-Bruxelles (Belgique).
